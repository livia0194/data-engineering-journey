# Cheat sheet

## Daily save loop
git status                  # what changed?
git add .                   # stage everything
git commit -m "message"     # save a snapshot
git push                    # upload to GitHub

## Running Python
uv run python file.py       # run a file
uv add package-name         # install a library

## Moving around
pwd                         # where am I?
ls                          # what's here?
cd folder-name              # go into a folder
cd ..                       # go up one level
